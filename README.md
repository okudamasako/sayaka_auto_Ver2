# Sayaka Auto Ver2

SNS投稿文生成システム「Sayaka Auto Ver3」を開発する過程で、
動作検証・構成テスト用として制作したプロトタイプです。

## 概要

テーマ・プラットフォーム・文体を入力すると、
AIがSNS投稿文を生成するWebアプリです。

Ver3開発前の実験環境として、
投稿生成・外部連携・運用フロー検証を行っていました。

## 主な機能

- SNS投稿文生成
- Threads / Instagram / X向け投稿生成
- OpenAI API連携
- 投稿生成フロー検証
- Next.jsベースのUI構築
- 外部サービス連携テスト

## 使用技術

- Next.js
- OpenAI API
- Vercel
